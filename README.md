# ECPI ePortfolio Lesson

Interactive HTML lesson introducing students to professional ePortfolios, recommended sections, professional design, vibe coding, GitHub Pages, the ECPI ePortfolio Coach, reflection, and formative knowledge checks.

## Before publishing

1. Open `index.html`.
2. Search for `ASSISTANT-LINK-GOES-HERE`.
3. Replace it with the actual ECPI ePortfolio Coach URL.
4. Upload `index.html` to the root of the GitHub repository.
5. Enable GitHub Pages from the `main` branch and `/ (root)` folder.
